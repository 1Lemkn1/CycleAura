# CycleAura

Локальный трекер цикла на React, TypeScript, Vite и Tailwind CSS. Формат данных и ключ `lunacare-data-v1` сохранены. Записи не отправляются на сервер.

## Структура

- `src/App.tsx`: сборка приложения и выбор вкладки.
- `src/store.ts`: профиль, записи и localStorage.
- `src/lib/cycleModel.ts`: чистая общая модель дат, фаз, прогноза и истории.
- `src/hooks/useCycleModel.ts`: мемоизация модели и обновление локальной даты в полночь или после возвращения в приложение.
- `src/lib/cycleValidation.ts`: общая проверка дат при создании и редактировании.
- `src/lib/cycleContent.ts`: подписи и поддерживающие тексты.
- `src/utils/date.ts`: локальные календарные даты и форматирование.
- `src/components/CycleOrb.tsx`: круг с прогнозом, задержкой или первым шагом.
- `src/components/CycleOverview.tsx`: круг и информационные облачка.
- `src/components/CycleGuidance.tsx`: подсказки и объяснение прогноза.
- `src/tabs/`: отдельные страницы приложения.
- `tests/cycleModel.test.ts`: регрессионные проверки расчётов и валидации.

## Правила расчёта

Запись хранит первый и последний день менструации. Менструальный цикл при этом продолжается до следующего начала, даже после отметки окончания месячных.

Средняя длина цикла считается по известным интервалам между началами. Пока нет двух начал, используется явно обозначенный ориентир 28 дней. Длительность месячных считается включительно по реальным датам.

Прогноз для каждого исторического цикла опирается только на интервалы, известные к его началу. Добавление последующих записей не стирает историческую задержку. Редактирование или удаление более ранних записей намеренно пересчитывает последующие прогнозы.

В ожидаемый день счётчик задержки равен нулю; на следующий день равен одному. После наступления задержки календарь выделяет прошедшую ожидаемую дату и дни ожидания по сегодняшний день. Будущие даты не обозначаются как состоявшаяся задержка. Новое фактическое начало всегда имеет приоритет.

Фертильное окно и овуляция являются расчётными. Календарь не подтверждает овуляцию, не является методом контрацепции и не заменяет медицинскую консультацию. В истории «без месячных» означает фактический промежуток без кровотечения, а не отсутствие вероятности беременности.

## Проверки

Тесты используют встроенный `node:test`, без дополнительных зависимостей. Для Node.js 22.18 или новее: `node --experimental-strip-types --test tests/cycleModel.test.ts`. Для проверки часовых поясов можно повторить запуск с `TZ=Europe/Moscow`, `TZ=Europe/Berlin` и `TZ=America/New_York`.

Вручную стоит проверить первый вход без данных, сохранение начала и окончания, повторную загрузку, редактирование и удаление, счётчик в ожидаемый день и после него, календарь на границе месяца, переход даты в полночь и возврат после сна телефона. Анимации учитывают `prefers-reduced-motion`.

Тексты о тесте при возможной беременности сверены с [NHS Wales](https://111.wales.nhs.uk/livewell/pregnancy/whentest/). Подсказка обратиться к врачу при сохраняющейся задержке или беспокойстве не является диагнозом.
